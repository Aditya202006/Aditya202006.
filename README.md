**Tech Stack:** React.js, Vite, Node.js, Express.js, MongoDB, Clerk Authentication, Nodemailer

- Request and acceptance management
- Backend REST APIs
- Email notifications
- MongoDB-based data persistence

### 2. QueryScope — SQL Query Visualizer & Analyzer

An interactive SQL learning platform designed to help developers understand SQL query structure, execution order, and optimization concepts.

**Tech Stack:** React.js, Vite, Node.js, Express.js, Tailwind CSS

**Key Features:**
- SQL query analysis and visualization
- Query clause extraction
- SQL execution order representation
- Query statistics and analysis
- Query optimization insights
- AI-powered interview preparation features
